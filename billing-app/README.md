# Tagihanku — Billing App

Aplikasi billing web berbasis PHP Native + MySQL untuk membuat, mengirim, dan mengelola tagihan dengan link pembayaran unik.

## ✨ Fitur
- Manajemen tagihan (single & bulk)
- Payment link generator
- Multi metode pembayaran (QRIS, bank, e-wallet)
- Konfirmasi pembayaran real-time
- Notifikasi WhatsApp dengan template dinamis
- Struk digital (thermal-style)
- Dashboard admin dengan statistik

## 🛠️ Tech Stack
- PHP Native 7.4+
- MySQL / MariaDB
- Vanilla JavaScript
- HTML5 + CSS3

## 🚀 Cara Install
1. Clone repo ini
2. Copy `config.example.php` → `config.php`
3. Isi kredensial DB di `config.php`
4. Import `database.sql` ke MySQL
5. Upload ke hosting / akses via localhost
